Earlier experiments (highway, archived)

This was the "earlier experiments" part of the README before the docs were simplified on 2026-11-15.

Experiments 1–4 used the plain highway setup, where messages turned out to carry little information the ego could not already infer. Their code, data, and weights are in archive/, and their write-ups are in docs/archive.

<details> <summary><strong>Experiment 1 — DQN request policy (1,000 episodes)</strong></summary>

The current DQN request-policy experiment uses:

  • 1000 training episodes
  • 1e-5 learning rate
  • 0.3 communication cost per request
  • Visible-neighbor request masking
  • Five-step MCP planning
  • MLP checkpoint: archive/legacy_single_request/checkpoints/MLP/best.pt

The DQN learns to request information from visible neighboring vehicles or choose no request. The archived training results are stored under archive/legacy_single_request/results/DQN/.

Supporting MLP world model

The supporting MLP world-model run trained for 50 epochs. Its best and final test loss was approximately 0.3922 at epoch 50:

<details> <summary><strong>Experiment 2 — DQN resumed training (1,000 → 2,000 episodes)</strong></summary>

The resumed run achieved an average reward of 8.67, compared with 6.42 for the previous 1000-episode run. Communication cost decreased as the policy requested information less often. The run is stored under:

archive/legacy_single_request/results/DQN/

The reward improved, but the DQN loss remained unstable, so the policy should be evaluated against a no-request baseline before drawing final conclusions.

<details> <summary><strong>Experiment 3 — MLPx + DQNx multi-request communication</strong></summary>

This experiment extends the original request policy so the ego vehicle can request information from multiple visible neighboring vehicles at the same timestep. MLPx predicts the next observation and reward from the current observation, driving action, request mask, and received messages. DQNx chooses the request mask, while the five-step MCP planner uses MLPx to choose the driving action.

The recorded DQNx run used:

  • 2,000 episodes;
  • ten request slots with visibility masking;
  • a 0.3 communication cost per requested vehicle;
  • real environment transitions for DQNx training; and
  • MLPx plus five-step MCP planning for the driving action.

MLPx results

The best MLPx test losses were approximately:

RunEpochsBest test lossBest epoch
20261112_132150_mlpx1000.429230
20261112_132315_mlpx2000.432924

The second run became worse after its early best epoch, suggesting overfitting or limited data diversity. The best.pt checkpoint should be used for planning.

DQNx results

For the final 100 episodes of the recorded run:

  • mean reward: approximately 10.93;
  • mean DQNx loss: approximately 5.02;
  • mean requests: 0.82 per episode; and
  • mean communication cost: approximately 0.246.

The policy often selected no requests. This lowers communication cost, but it must be compared against no-request and random-request baselines before being considered successful communication learning.

The archived training artifacts are stored under archive/pre_ttc_multirequest/results/MLPx/experiments/ and archive/pre_ttc_multirequest/results/DQNx/experiments/.
