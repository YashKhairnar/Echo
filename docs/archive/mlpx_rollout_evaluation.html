MLPx Rollout Evaluation

The MLPx world model was tested against real HighwayEnv transitions. From the same sampled state, the evaluator compared all five driving actions over a short constant-action rollout.

Run the evaluation with:

PYTHONPATH=. .venv/bin/python -m scripts.evaluate_mlpx_rollout \
    --episodes 10 \
    --states-per-episode 3 \
    --horizon 3 \
    --message-mode none

The evaluator reports next-state MAE, rollout reward MAE, and action-ranking agreement: how often MLPx selects the same best action as the real environment.

Some sampled episodes ended before the complete horizon, so only complete rollouts were included.

Interpretation

Three-step planning is currently more reliable than five-step planning. The shorter horizon reduces accumulated prediction error and improves reward prediction and action ranking.

The active MCP planner therefore uses a three-step horizon. MLPx is useful for short-horizon planning, but it should not yet be treated as a reliable five-step simulator.
