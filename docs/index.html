Project workflow

  1. Create the environment with a controlled ego and aggressive/defensive background vehicles.
  2. Filter visible neighbors and optionally request their next-action intent.
  3. Use the rule or learned planner to choose an ego action.
  4. Evaluate transitions and store state, messages, action, next state, reward, and episode flags.
